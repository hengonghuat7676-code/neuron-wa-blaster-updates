# Neuron WA Blaster v3.4.5

- Check GitHub for updates on every app startup, about 1.8 seconds after the UI initializes.
- Remove the 24-hour check suppression and hourly background polling.
- Show an Update Available popup only when a newer release is found.
- Keep automatic checks quiet when up to date or when the check fails; manual checks show the result.
- While Sending, Account Warming or WA Filter is active, hide Update Now and offer Update After Process or Update Later.
- Update After Process reminds you after all active tasks finish or pause; it never installs without confirmation.
- Preserve dynamic version labels and the tested portable updater launcher.

Use Settings > Check for Updates in v3.4.4 to install this release. For older
versions whose updater fails, download and run the new portable EXE manually.
